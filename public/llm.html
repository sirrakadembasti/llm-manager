                Graphify ile daha güçlü proje analizi
                
Graphify kod ilişkilerini çıkarır; kaynaklı sohbet ve geliştirme görevlerinde ilişkili dosyaları bulmaya yardımcı olur.

                
Graphify resmî deposu ve kurulum rehberi

                
LLM Manager'ın çalıştığı sunucuda Python 3.10+ ile uv tool install graphifyy veya ayrı bir Python ortamında python -m pip install graphifyy kullanın. Paket adı çift y içerir.

                
Kurulumdan sonra Projeyi tara düğmesine basın. Sunucunun PATH dizinindeki graphify otomatik aranır. Bulunamazsa sunucu yöneticisi LLM_GRAPHIFY_PYTHON ile kurulumun Python yolunu belirtir. PATH değiştiyse servisi yeniden başlatın.

                
Sohbette / komutu gerekmez. Bu entegrasyon için graphify install gerekli değildir. Kod ilişkileri yerel ve code-only taranır; README ve kılavuzlar ayrıca kaynak bağlamına seçilir. Kaynaklı sohbet için paylaşım onayı gerekir.
